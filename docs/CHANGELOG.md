## 一、功能主线（按主题归集，跨版本合并）

### 1. 收藏：入口、类型与数据安全
- **快速收藏**（0.1.0）：文本 / Markdown / 图片（含全局快捷键保存剪贴板），点击卡片一键复制（图片复制原图）。
- **类型判定收敛（0.2.0 → 0.4.4 定稿）**：Markdown 自动判定从「多行即 md」一路收紧到块级特征，最终**彻底废弃自动判定**——剪贴板与「收藏文本」一律按**文本**原样保存（0.4.4 定稿）。0.6.0 起保存视图**明示当前按哪种标记收藏**、一键切换为 Markdown；多行内容（SQL/日志/代码）的「收藏文本」「收藏 Markdown」两个入口始终可选（0.6.1 修复其被 uTools exclude 隐藏的根因）；兼容对象/数组形态的 payload。
- **未保存保护（0.4.8 / 0.4.9 定稿）**：内容 / 标签 / 备注任一改动后，Esc 或「取消」弹「未保存的修改」确认框；只打开不改动不弹。离开去向按来源定：主面板进入（或编辑）→ 回主面板；uTools 指令新建 → 退出插件。

### 2. 标签系统
- **标签管理**（0.1.0）：新建 / 重命名 / 删除；0.4.0 起多选批量删除、按最近使用排序；0.3.0 起管理弹窗搜索过滤。
- **选择标签语义（0.2.0 起 ↑/↓ + 回车 + Esc；0.6.0/0.6.1 定稿）**：**直接回车 = 新建标签，↓ 选中后回车 = 选那一项**；输入框空白回车 = 浏览全部已存在标签；筛选词一变，↓ 从第 1 项重新开始。
- **token field 重构（0.6.3）**：标签与输入框合为一个容器——光标紧贴标签、退格即删"所见"；第一次退格只标红、再按才删，**长按不成串清空**；点 `×` 精确删除；标签按**添加顺序**显示，保存统一按拼音排序落库（跨记录、跨搜索一致）。
- **拼音选标签（0.5.6）**：输入 `qd` / `qianduan` 直接搜出「前端」（全拼 + 首字母）。

### 3. 标签建议下拉：弹层与键盘手感（0.4.1~0.6.8 同题系列，归集为一条）
一个浮层前后修了六轮，根因层层递进（排查全史见 CHANGELOG-DETAIL）：
- **弹层定位**（0.4.2~0.4.6；0.6.0 定稿）：从被裁剪 / 撑开表单，到自适应方向，最终定为**相对输入容器内联展开**（紧贴上下沿，滚动/缩放跟随）。
- **高度与滚动几何**（0.6.1 / 0.6.5）：可视高度按真实可用空间给足、按**实测行高**取整行，滚动逐行对齐，不再"遮半行 / 跳行"。
- **高亮抢占**（0.6.6 / 0.6.7）：**键盘导航是粘性 `kbdNav` 模式，不能用计时时间窗**（会过期）；只有真实 `mousemove` 才退出键盘模式，鼠标与键盘互不干扰。
- **最终根因（0.6.8）**：`document` 上的 capture scroll 监听连**下拉自身的滚动**也捕获，触发候选列表**整表重建**（高亮清零、scrollTop 回顶）——此前四轮没修对，均因 jsdom 不派发 scroll 事件、该路径从未被测试执行过。现重定位监听忽略来源为下拉自身的 scroll，行为收敛稳定。

### 4. Markdown 编辑器
- **三模式编辑**（0.1.0 富文本 / 源码 / 预览）。
- **引擎重写（0.5.0）**：迁移到 **Tiptap 3（ProseMirror）**，工具栏命令化，新增下划线 / 表格 / 撤销重做；粘贴清洗、列表续编、IME 组合由引擎原生解决。
- **代码块体系（0.5.0~0.5.5）**：语法高亮（hljs）+ 语言角标（自动识别）、语言选择器写入围栏、选多行合并为**一个**代码块、末行 ↓ 退出；悬停「复制」按钮（不侵入编辑器内部 DOM）。
- **表格体系（0.5.1 / 0.5.2）**：行列增删、**8×8 矩阵选择器**；富文本↔源码往返用自研 table 规则，空白单元格不再碎裂丢内容。
- **回车语义定稿（0.5.2 → 0.5.4）**：**回车 = 新段落、Shift+Enter = 段内换行**（Typora 同款行业标准）；做块级格式前先按选区边界切块，H1 / 列表 / 引用只作用于选中文字。
- **链接（0.5.1）**：「插入链接」对话框（文字 + 网址）；所有链接一律系统浏览器打开。

### 5. 主面板：浏览、检索与效率
- **全文搜索**（0.1.0）：内容 / 标题 / 备注 / 标签，多关键词 AND；**0.5.6 起支持拼音**（`qd` 找「前端」，设置可开关）。
- **内置搜索框 + 键盘选卡片**（0.2.0 起）：↑/↓ 选择、回车复制、Esc 清空；进入自动聚焦，uTools 带词进入自动预填（0.3.0 补全）。
- **排序与分组（0.6.0，选定即记住）**：更新 / 创建 / 最近使用 / 使用次数 / 标题 / 类型（搜索时另有相关度），可反向、可按日期分组；**关掉再开仍按上次设定**；卡片显示「使用 N 次 · 最近使用」。
- **批量删除（0.6.0）**：复选 / 全选 / 反选，确认框写明条数，图片一并清理本地文件；Esc 先退批量。
- **预览弹窗（0.4.11）**：完整内容 + 备注 / 标签 / 时间，弹窗内可直接复制；0.5.6 加「编辑」直达修改。
- **早期打磨（0.3.0）**：卡片布局紧凑、备注强调色、「更多标签」多选筛选。

### 6. Esc 交互语义（0.4.7 → 0.4.10 定稿，长期不变）
- **Esc 永远只退出当前一层**：建议列表 → 弹窗 → 重命名 → 保存视图（有改动弹确认 / 无修改离开）→ 主面板清空搜索词 → 退出插件。实现在集中式 Esc 栈，capture 拦截 uTools 全局退出。

### 7. 设置项（累计）
- 成功提示三选一：轻量气泡（默认）/ 完整浮层 / 不提示（0.3.0 起）。
- 「⚡ 复制后立即关闭窗口」（0.4.12，默认关）：复制成功即刻回原工作窗。
- 「🪟 Windows 系统消息提示」（0.5.6，默认开）。
- 「拼音匹配」（0.5.6，默认开）。
- 「默认排序」（0.6.0）：方式 / 方向 / 是否按日期分组；「恢复默认」保留用户显式选定的排序。

### 8. 工程与交付
- `npm run pack`：版本一致性校验（0.2.0）、自动清理旧版本发布物（0.4.11）。
- Agent 文档体系：AGENTS.md 单点 + 各工具薄引用入口（0.4.10）；2026-09-20 完成四层渐进披露改造——AGENTS/WORKMETHOD 抽为**零项目内容的通用模板核心**（可复制到非编码项目），HANDOFF 承载项目全部情报与硬规则；TODO 与 CHANGELOG/CHANGELOG-DETAIL 归入 `docs/`，并新建 docs/traps/*（模块陷阱档案）。
- 可选真实浏览器（playwright）回归用例 `npm run test:browser`（0.6.8 起）。

## 三、记录规则（0.6.8 定稿）
1. 0.6.9 起新条目**按版本追加**，每版至多三条：新增 / 变更 / 修复，每条一两句。
2. **同一问题跨版本的重复修订不再另立长条目**：归并进「功能主线」对应主题小节（标量版本号）；若真因有新发现，在主题小节追加一行，过程细节写 CHANGELOG-DETAIL.md。
3. 测试数量、排查过程、假绿灯教训等开发层记录：产物级坑与禁令进 HANDOFF（唯一出处），过程记录进 CHANGELOG-DETAIL，本文件不再承载。
